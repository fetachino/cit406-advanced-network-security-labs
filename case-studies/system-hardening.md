# Windows and Linux System Hardening

## Objective

Reduce host attack surface through configuration changes and validate the resulting security posture.

## Windows work

- Reviewed local accounts and guest-account state.
- Strengthened password and account-lockout policies.
- Enabled auditing to improve accountability and investigation readiness.

## Linux work

- Restricted unnecessary services.
- Applied host-firewall controls and safer file permissions.
- Added integrity-oriented checks for scheduled tasks.
- Ran a Lynis audit and used its recommendations to identify remaining gaps.

Hardening is iterative: changes should be documented, validated, and monitored to avoid operational problems.

# Network Traffic Analysis

## Objective

Capture and analyze network traffic, then distinguish expected behavior from activity requiring investigation.

## Approach

1. Enumerated capture interfaces and selected the active adapter.
2. Captured traffic with Tshark and reviewed it with Wireshark.
3. Verified ICMP behavior and examined TCP and QUIC traffic.
4. Used filters, protocol hierarchy, and conversation statistics to identify communication patterns.
5. Documented a reproducible analysis workflow.

## Outcomes

- Built familiarity with packet fields, protocol relationships, and encrypted-traffic indicators.
- Compared Wireshark's interactive workflow with Tshark's command-line workflow.
- Practiced explaining evidence without exposing raw captures or endpoint details.
